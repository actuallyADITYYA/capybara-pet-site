Know when your AI coding agent is done, without watching the terminal

AI coding agents like Claude Code work for minutes at a time, and nobody wants to stare at a terminal. Capybara Pet sits on your desktop, shows when the agent is busy, and hops when it is done.

The problem with long agent runs

You send Claude Code a task, switch to another window, and then spend the next ten minutes wondering whether it has finished, is waiting for permission, or got stuck. Notification sounds are easy to miss and system notifications are easy to dismiss. A small animated character in the corner of your screen is hard to miss, and pleasant to look at.

What Capybara Pet does while an agent works

  • Busy: when you send a prompt, he pulls out a phone, furrows his brow and sweats while the agent works.
  • Done: when the agent finishes, he does a happy hop with sparkles and a squeak.
  • Needs you: when Claude Code asks for permission or input, he hops too, so you know it is waiting for you.
  • Typing wins: if you start typing, he swaps the phone for his keyboard, then goes back to the phone.

Set up Claude Code in one click

Right-click the capybara (or open the menu bar or tray icon) and choose Connect Claude Code. Capybara Pet adds the required hooks to ~/.claude/settings.json, saves a backup next to it and leaves your other settings untouched. Start a new Claude Code session afterwards, because hooks are read when a session starts.

Works with other agents too

Capybara Pet listens on a local address that never leaves your computer: http://127.0.0.1:47831. Anything that can run a shell command or send an HTTP request when it starts and finishes can drive him, including Codex CLI, Cursor, Aider, Gemini CLI and your own scripts.

curl http://127.0.0.1:47831/event/thinking   # busy: phone out, sweating
curl http://127.0.0.1:47831/event/done       # happy hop
curl http://127.0.0.1:47831/event/idle       # back to normal

Private and local

The agent connection is a request to your own machine. Nothing about your code, prompts or sessions is sent to Capybara Pet, only the three words above. If an agent run is interrupted and never reports back, he returns to normal on his own after three minutes.

Frequently asked questions

Does it work with Claude Code?

Yes. Choose Connect Claude Code from his menu and he is set up in one click, using Claude Code hooks.

Does it work with Codex, Cursor or other agents?

Yes, with any tool that can run a command or make an HTTP request when it starts and finishes. Call the /event/thinking and /event/done addresses on 127.0.0.1:47831.

Does it send my code anywhere?

No. The connection is a request to your own computer, and only the words thinking, done or idle are sent.

What if my agent crashes and never says it is done?

Capybara Pet returns to normal on his own after three minutes without any agent activity.
